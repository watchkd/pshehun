# 盘叔合婚 · pshehun

> **一句话定位**：输入双方四柱，或双方公历生日加出生时刻，输出一份双盘并排的合婚书（Markdown 骨架 + 单文件 HTML）。

本技能包纯 Python 标准库实现，零第三方依赖，不联网、不调外部接口、不写系统目录。排盘与排印由脚本负责，模型只负责按六轴流程断盘并填写 `duan.json`。

## 一、安装

1. **环境**：Python 3.8 及以上，无需 `pip install` 任何包。Windows / macOS / Linux 均可。
2. **放置**：把整个 `pshehun` 目录原样放进你的技能系统目录（例如 `skills/pshehun/`），保持目录层级不变——`references/`、`tools/`、`assets/` 是相对包根定位的，改名或拆层会导致脚本与索引失效。
3. **识别入口**：`SKILL.md` 文件头部的 YAML frontmatter 即技能注册信息，其中 `name` 为技能标识（`pshehun`），`description` 为触发描述。技能系统读这两个字段决定何时启用本技能，不要删改。
4. **自检**：装好后先跑一次脚本自检，确认环境可用。

```bash
python tools/paipan.py --self-test
python tools/hehun.py --self-test
```

| 项 | 是否必填 | 格式 | 缺了会怎样 |

| **性别**（双方各自） | **必填** | 男／女 | 一方性别不明则不取夫星妻星，只做画像取象；连男女都不明则停手问明，不排盘 |

| **出生时刻**（双方各自） | **必填** | `HH:MM`，24 小时制 | **缺即停手**，先问时刻；问不到只出三柱，并停用轴1 八法八格、轴5 应期、轴6 子女 |
| 出生地经度 | 可选 | 东经为正、西经为负，两人共用一个 | 不给则按北京时间排，报告抬头标注「未校正（按北京时间）」，边界时辰建议补经度复核 |
| 关系形态 | 可选 | 未婚／已婚／离异／同居 | 未说明按未婚处理，报告首段注明该假定 |
| 提问落点 | 可选 | 合不合／婚期／婚后经营／复核旧说法 | 未说明按八段完整输出，不额外收缩 |

补充两条硬约束：

- **农历不代为换算**。本技能只吃公历，请先自行转换或提供万年历结果；不凭记忆推算农历，也不先排一版「看着像」的四柱凑合。
- **双人须一男一女**。同性关系不在覆盖范围内，脚本直接报错退出，不折算、不改写成「朋友关系」绕过。

## 四、信息不全时会怎么追问

本技能的设计前提是：**缺项就问，不猜、不补、不凑盘**。

1. **只给了一方信息 → 说明单盘出不了合婚结论**，把另一位的性别、公历生日、出生时刻一次问齐，而不是先排一半的盘就下判断。
2. **缺出生时刻 → 先问，且只问一次**。会先问「出生大概几点？有出生证明或长辈记忆都行」。不猜午时、不猜子时、不按「大概是下午」取一个钟点。
3. **问不到时刻 → 只出三柱**，并在报告里明确写出停用范围：轴1 八法八格不取格、轴5 应期不给年月、轴6 子女部分不判。三柱只给粗线条——旺衰总量、日支夫妻宫的形状、年月的原生一侧，不给婚期、不做宫位强弱的细致比较。
4. **报的是农历 → 请你先转公历**。会明确说明本技能不内置农历换算，无法保证闰月与大小月准确，请提供已转换的日期。
5. **只给了四柱但没说哪一柱 → 会请你说清四柱顺序**（年、月、日、时），避免把月柱当日柱断。

追问轮次有上限，问不到就降级出三柱并说明停用范围，不会反复纠缠。逐项清单与停用规则的完整条文见 [`references/输入契约.md`](references/输入契约.md)，技能内的会话级话术见 [`SKILL.md`](SKILL.md) 的「首次使用引导」一节。

## 五、输出长什么样

**固定八段**（对外交付顺序，技术顺序另算）：

1. 总断加置信度（一句话结论 + 星级）
2. 两人各自基线
3. 画像互验
4. 结构互补
5. 夫妻宫互动
6. 未来 3 年应期（标到年月，区分高置信与低置信）
7. 风险提示（折算成现代可读影响）
8. 附录（逐条出处 + 星级）

**HTML 版式的固定特性**：

- 双盘并排——乾造／坤造各一栏，含四柱、十神、藏干、纳音、旬空、五行、大运；
- 顶部锚点导航，长报告可跳段；
- 附录收进折叠块，需要时展开；
- 手机可读，窄屏下宽表格自动转纵向卡片，不出现横向滚动；
- 单文件自包含，零外链，二维码与插画一律 base64 内嵌，无 CDN、无 web font、无外部 CSS／JS。

**底部推广尾注**：每份报告末尾固定附一段「合婚之外」（赞赏码、微信码、苍盘命书体验邀请）。尾注每份报告只出现一次，同一对命造追问不重复推送，换新命造才重新附带；正文分析中不会把它当功能点提及。

## 七、硬边界与出处

**不覆盖、不硬套的情形**（不因用户坚持而放宽）：

1. 时辰不明或只给三柱——停用轴1 八法八格、轴5 应期、轴6 子女，只给三柱支持的粗线条；
2. 双盘案例实测样本为零——不给准确率、不给命中率数字，只给窗口与置信等级；
3. 同性关系、不婚、二婚等六部古籍无语料的形态——只把结构互补、宫位互动、应期窗口当通用技术层使用，其余不适用；
4. 纯神煞问答——桃花、孤辰、羊刃、生肖配对不作吉凶判据，给固定应答并说明成立条件；
5. 寿夭与具体岁数、品行与身份判定、投资疾病官司等非婚恋事项——一律不出结论。

**出处**：语料为六部古籍原文层，一律行号定位——《渊海子平》《三命通会》《五行精纪》《兰台妙选》《玉照定真经》《神峰通考》。编号体系（HH-R 规则条、H 命例、格 格局、C 冲突裁决、M 误区待裁、D 术语待裁）见 [`references/wenxian.md`](references/wenxian.md)。未被推翻前先按此执行的保守默认项，报告中会注明。
